Update various sw packages
run in Powershell


Powershell (needs elevated privilege)
winget install Microsoft.PowerShell
winget upgrade Microsoft.PowerShell


Git for Windows
winget install --id Git.Git -e --source winget
winget upgrade Git.Git

VS Code
winget install Microsoft.VisualStudioCode
winget upgrade Microsoft.VisualStudioCode

Python
winget install --id Python.PythonInstallManager --source winget
winget upgrade --id Python.PythonInstallManager --source winget
py install 3
py install --upgrade

After uninstall or major release, run-
py -m pip install --upgrade pip
py -m pip install --upgrade PyYAML
py -m pip install --upgrade wakepy

(to get PythonInstallManager from Microsoft Store: winget install 9NQ7512CXL7T)

winget install --id SQLite.SQLite
